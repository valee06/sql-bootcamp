# day06 — Ограничения и последовательности

Расширение базы новой таблицей персональных скидок: структура, наполнение данными, ограничения целостности, документация схемы и автоматическая генерация первичного ключа. База: [`db/after-day04.sql`](../db/after-day04.sql).

| Упражнение | Что делает скрипт |
| ---------- | ----------------- |
| `ex00` | таблица `person_discounts` с внешними ключами на клиентов и пиццерии |
| `ex01` | заполнение таблицы: размер скидки зависит от числа заказов клиента в пиццерии (10,5 % / 22 % / 30 %) |
| `ex02` | запрос заказов с ценой до и после скидки |
| `ex03` | составной индекс по `person_discounts(person_id, pizzeria_id)` и проверка плана запроса |
| `ex04` | `CHECK`-ограничения: обязательные поля, значение по умолчанию и диапазон скидки 0–100 |
| `ex05` | комментарии к таблице и столбцам (`COMMENT ON`) |
| `ex06` | последовательность `seq_person_discounts` как значение по умолчанию для первичного ключа |

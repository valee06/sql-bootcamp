# day07 — Агрегация и аналитические запросы

`GROUP BY`, `HAVING`, агрегатные функции и вычисляемые показатели по посещениям и заказам. База: [`db/after-day04.sql`](../db/after-day04.sql).

| Упражнение | Что делает запрос |
| ---------- | ----------------- |
| `ex00` | количество визитов каждого клиента |
| `ex01` | четыре самых частых посетителя по именам |
| `ex02` | три самые популярные пиццерии по визитам и три по заказам в одном результате с признаком `action_type` |
| `ex03` | общая популярность пиццерии: визиты плюс заказы |
| `ex04` | клиенты, у которых больше трёх визитов (`HAVING`) |
| `ex05` | список клиентов, делавших заказы, без дубликатов |
| `ex06` | по каждой пиццерии: число заказов, средняя, максимальная и минимальная цена |
| `ex07` | средний рейтинг пиццерий |
| `ex08` | число заказов по связке «адрес клиента — пиццерия» |
| `ex09` | показатель по адресам (макс. и мин. возраст, средний возраст) и логический признак сравнения через `CASE` |

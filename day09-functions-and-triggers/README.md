# day09 — Функции и триггеры

Бизнес-логика на стороне базы данных: аудит изменений через триггеры, SQL- и PL/pgSQL-функции. База: [`db/after-day04.sql`](../db/after-day04.sql).

| Упражнение | Что делает скрипт |
| ---------- | ----------------- |
| `ex00` | таблица аудита `person_audit` и триггер на `INSERT` в `person` |
| `ex01` | триггер на `UPDATE` (в аудит попадают старые значения) |
| `ex02` | триггер на `DELETE` |
| `ex03` | один общий триггер `fnc_trg_person_audit` вместо трёх отдельных; использует `TG_OP` |
| `ex04` | две SQL-функции, возвращающие клиентов по полу, — как альтернатива представлениям |
| `ex05` | одна параметризованная функция `fnc_persons` со значением по умолчанию вместо двух |
| `ex06` | PL/pgSQL-функция `fnc_person_visits_and_eats_on_date` с параметрами по умолчанию — функция-обёртка над запросом из предыдущих модулей |
| `ex07` | `func_minimum` — минимум из массива чисел с `VARIADIC` |
| `ex08` | `fnc_fibonacci(pstop)` — числа Фибоначчи меньше заданного предела (цикл в PL/pgSQL) |

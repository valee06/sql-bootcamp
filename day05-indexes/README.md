# day05 — Индексы

Создание индексов разных видов и проверка, что планировщик ими пользуется. Для доказательства в упражнениях отключается последовательное сканирование (`SET enable_seqscan = OFF`) и используется `EXPLAIN ANALYZE`. База: [`db/after-day04.sql`](../db/after-day04.sql).

| Упражнение | Что делает скрипт |
| ---------- | ----------------- |
| `ex00` | индексы для каждого внешнего ключа |
| `ex01` | `EXPLAIN ANALYZE`: проверка, что индексы по внешним ключам используются |
| `ex02` | функциональный индекс по `upper(name)` |
| `ex03` | многоколоночный индекс `person_order(person_id, menu_id, order_date)` |
| `ex04` | индекс `idx_menu_unique` по `menu(pizzeria_id, pizza_name)` и проверка плана запроса |
| `ex05` | частичный уникальный индекс с условием на дату заказа |
| `ex06` | индекс по рейтингу и план запроса с оконной функцией |

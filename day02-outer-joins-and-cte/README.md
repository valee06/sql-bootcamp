# day02 — Внешние соединения и CTE

`LEFT` / `FULL JOIN`, поиск пропусков в данных, генерация диапазона дат и общие табличные выражения. База: [`db/model.sql`](../db/model.sql).

| Упражнение | Что делает запрос |
| ---------- | ----------------- |
| `ex00` | пиццерии, которые никто не посещал (`LEFT JOIN ... IS NULL`) |
| `ex01` | дни, в которые клиенты 1 и 2 не заходили ни в одну пиццерию; диапазон дат через `generate_series` |
| `ex02` | `FULL OUTER JOIN` клиентов, визитов и пиццерий; пропуски заменяются через `coalesce` |
| `ex03` | та же задача, что `ex01`, но с `WITH` (CTE) |
| `ex04` | цены на две пиццы по пиццериям (`LEFT JOIN`) |
| `ex05` | клиентки старше 25 лет |
| `ex06` | пиццы и пиццерии по заказам двух клиентов |
| `ex07` | CTE с «недорогими» пиццериями и визиты клиента в них за один день |
| `ex08` | клиенты-мужчины из двух городов, заказывавшие определённые пиццы |
| `ex09` | клиентки, заказывавшие и пепперони, и сырную пиццу |
| `ex10` | пары клиентов из одного города (соединение таблицы с самой собой) |

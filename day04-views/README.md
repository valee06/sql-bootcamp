# day04 — Представления

Обычные и материализованные представления. Начинать нужно с базы, собранной скриптом [`db/after-day03.sql`](../db/after-day03.sql). После модуля состояние для следующих дней восстанавливается скриптом [`db/after-day04.sql`](../db/after-day04.sql) (представления в конце удаляются).

| Упражнение | Что делает запрос |
| ---------- | ----------------- |
| `ex00` | два представления `v_persons_female` и `v_persons_male` по полу клиентов |
| `ex01` | имена всех клиентов, собранные из двух представлений через `UNION` |
| `ex02` | представление `v_generated_dates` с днями января 2022 (`generate_series`) |
| `ex03` | дни, в которые не было визитов, на основе `v_generated_dates` |
| `ex04` | представление `v_symmetric_union`: симметрическая разность двух множеств клиентов через `EXCEPT` и `UNION` |
| `ex05` | представление `v_price_with_discount`: заказы с ценой со скидкой 10 % |
| `ex06` | материализованное представление `mv_dmitriy_visits_and_eats` |
| `ex07` | добавление данных и `REFRESH MATERIALIZED VIEW` |
| `ex08` | удаление всех созданных представлений |

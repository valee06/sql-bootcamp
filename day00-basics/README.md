# day00 — Реляционная модель и базовый SQL

Первые запросы к базе пиццерий: фильтры, сортировка, вычисляемые поля и вложенные запросы. База: [`db/model.sql`](../db/model.sql).

| Упражнение | Что делает запрос |
| ---------- | ----------------- |
| `ex00` | имена и возраст клиентов из Казани |
| `ex01` | женщины из Казани, сортировка по имени |
| `ex02` | пиццерии с рейтингом от 3,5 до 5 — двумя синтаксически разными запросами (сравнения и `BETWEEN`) |
| `ex03` | клиенты без дубликатов, которые посещали пиццерии в период или заходили в конкретную пиццерию |
| `ex04` | одно вычисляемое поле `person_information`, собранное из нескольких столбцов через `concat` |
| `ex05` | имена клиентов по заказам на выбранную дату, имя берётся вложенным запросом в `SELECT` |
| `ex06` | то же с логическим признаком `check_name` через `CASE` |
| `ex07` | возрастные интервалы клиентов (`interval_info`) через `CASE` |
| `ex08` | заказы с чётными идентификаторами |
| `ex09` | имена клиентов и пиццерий по визитам за период; сортировка в разных направлениях |

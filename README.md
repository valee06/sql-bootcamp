# SQL Bootcamp

Сборник решений курса по SQL и PostgreSQL: от первых `SELECT` до оконных запросов, индексов, транзакций, триггеров и рекурсивных запросов. Все задания построены вокруг одной учебной базы — сети пиццерий: клиенты, пиццерии, меню, визиты и заказы.

Репозиторий включает 10 индивидуальных модулей и один командный проект. Все скрипты проверены на PostgreSQL 16 и выполняются без ошибок. Исключение по способу запуска — `day08`: его сценарии рассчитаны на два параллельных сеанса `psql`.

## База данных

Схема и данные лежат в [`db/model.sql`](db/model.sql). В базе пять таблиц:

| Таблица | Содержимое |
| ------- | ---------- |
| `person` | клиенты: имя, возраст, пол, город |
| `pizzeria` | пиццерии и их рейтинг (0–5) |
| `menu` | пицца и цена в каждой пиццерии |
| `person_visits` | кто, когда и в какую пиццерию приходил |
| `person_order` | кто, когда и что заказывал |

Некоторые модули меняют данные, а последующие рассчитывают на изменённое состояние. Чтобы можно было начать с нужного места, в [`db/`](db) лежат два скрипта, которые собирают базу целиком вместе с результатами предыдущих модулей:

| Скрипт | Состояние базы |
| ------ | -------------- |
| `db/model.sql` | исходное — для `day00` … `day03` |
| `db/after-day03.sql` | с учётом изменений данных из `day03` — для `day04` |
| `db/after-day04.sql` | после `day04` (представления удалены) — для `day05` … `day09` |

## Как запустить

Нужен PostgreSQL (проверено на версии 16) и `psql`.

```bash
createdb pizza_db
psql -d pizza_db -f db/model.sql                        # day00 … day03
psql -d pizza_db -f day00-basics/src/ex00/day00_ex00.sql
```

Для следующих модулей создайте базу заново из соответствующего скрипта (`after-day03.sql` или `after-day04.sql`).

Командному проекту `team00-traveling-salesman` база с пиццериями не нужна: скрипт `ex00` сам создаёт свою таблицу и заполняет её данными.

### Модуль `day08`

Упражнения этого модуля — сценарии для **двух параллельных сеансов** `psql`. В `.sql`-файлах команды размечены комментариями `-- session #1` и `-- session #2`; их нужно выполнять по очереди в двух разных терминалах. В каждой папке лежат два скриншота с выводом `psql` для первого и второго сеанса.

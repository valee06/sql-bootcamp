# day01 — Операции над множествами и соединения

`UNION`, `INTERSECT`, `EXCEPT`, декартово произведение и разные способы соединять таблицы. База: [`db/model.sql`](../db/model.sql).

| Упражнение | Что делает запрос |
| ---------- | ----------------- |
| `ex00` | `UNION ALL`: идентификаторы и названия блюд меню вместе с клиентами в одном списке |
| `ex01` | `UNION ALL` двух отсортированных подзапросов: имена клиентов, затем названия пицц |
| `ex02` | `UNION` убирает дубликаты названий пицц |
| `ex03` | `INTERSECT`: дни, когда клиент и заказывал, и посещал пиццерию |
| `ex04` | `EXCEPT ALL`: клиенты, сделавшие заказ в день, когда не было визита |
| `ex05` | `CROSS JOIN`: все пары «клиент — пиццерия» |
| `ex06` | `INTERSECT` с именами клиентов вместо идентификаторов |
| `ex07` | `JOIN` заказов и клиентов, поле с информацией о клиенте |
| `ex08` | тот же результат через `NATURAL JOIN` |
| `ex09` | пиццерии без визитов: вариант с `NOT IN` и вариант с `NOT EXISTS` |
| `ex10` | соединение четырёх таблиц: кто, что и где заказал |

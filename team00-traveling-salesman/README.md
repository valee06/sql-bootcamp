# team00 — Задача коммивояжёра на SQL

Командный проект: классическая задача коммивояжёра (TSP), решённая средствами SQL. Нужно обойти все города ровно по одному разу и вернуться в исходный город так, чтобы суммарная стоимость пути была минимальной.

Граф из четырёх городов `a`, `b`, `c`, `d` хранится в таблице `path_cost(point1, point2, cost)`; стоимость симметрична, поэтому для каждой пары записаны оба направления. Решение — рекурсивный запрос `WITH RECURSIVE`, который собирает все маршруты из города `a` и отбрасывает те, где города повторяются.

| Упражнение | Задача | Результат на тестовом графе |
| ---------- | ------ | --------------------------- |
| `ex00` | создать таблицу, заполнить данными и найти все маршруты с минимальной стоимостью, начиная с города `a` | `80 — {a,b,d,c,a}` и `80 — {a,c,d,b,a}` |
| `ex01` | дополнить запрос так, чтобы он показывал и самые дорогие маршруты | к маршрутам со стоимостью 80 добавляются четыре маршрута со стоимостью 95 |

Запуск (`ex00` создаёт таблицу и заполняет её, поэтому его нужно выполнить первым):

```bash
psql -d pizza_db -f src/ex00/team00_ex00.sql
psql -d pizza_db -f src/ex01/team00_ex01.sql   # использует таблицу path_cost из ex00
```
